## Currently Building
### [Scheduled Protocol](https://github.com/Steven-Ens/Scheduled-Protocol)
A protocol for scheduling future transactions (one-time and recurring) on Arbitrum One.
* Designing and developing Solidity smart contracts for permissionless scheduled USDC payments on Arbitrum One, supporting one-time and recurring execution.
* Engineering a Rust executor using Alloy and Tokio to discover scheduled payments from on-chain events, validate execution eligibility, simulate transactions, and submit due payments.
*Building a lightweight TypeScript frontend using viem for wallet connectivity, payment creation, and status tracking.
